## 문제: 두 번째로 작은 수

배열 `arr`에서 **두 번째로 작은 수**를 반환.

```python
arr = [3, 1, 4, 1, 5, 9, 2, 6]
# expected: 2
```

**중복 처리**: 같은 값은 한 번만.

- `[1, 1, 3]` → 3 (두 번째로 작은 다른 값)
- `[1, 1]` → None
- `[5]` → None

**제약**:

- `sorted`, `set` **금지**
- **한 번 순회**
