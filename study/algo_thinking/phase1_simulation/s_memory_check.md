## 문제: 두 번째로 큰 수

배열 `arr`에서 **두 번째로 큰 수**를 반환.

```python
arr = [3, 1, 4, 1, 5, 9, 2, 6]
# expected: 6
```

**중복 처리**: 같은 값은 한 번만. 예:

- `[5, 5, 3, 1]` → 3 (두 번째로 큰 건 3)
- `[5, 5]` → 없음 (반환값 자유 — None 또는 -1 등 일관성만)

**제약**:

- `sorted`, `set`, `max` 두 번 사용 **금지**
- **한 번 순회**로 풀기

## 풀이

```
[2] 손풀이 (arr = [3, 1, 4, 1, 5, 9, 2, 6]):
    | i | arr[i] | max_num_list  | 변수2 | ... |
    | 0 |    3   | [3]           |       |     |
    | 1 |    1   | [3,1]         |       |     |
    | 2 |    4   | [4,3]         |       |     |
    | 3 |    1   | [4,3]         |       |     |
    | 4 |    5   | [5,4]         |       |     |
    | 5 |    9   | [9,5]         |       |     |
    | 6 |    2   | [9,5]         |       |     |
    | 7 |    6   | [9,6]         |       |     |
    종료 → 답: ?


[3] Invariant:
    "i번째 원소까지 본 시점에, max_num_list는 arr[0..i]의 원소 중 가장 큰 값과 두 번째로 큰 값을 가지고 있는 리스트이다."

    체크:
    - [O] "두 번째로 큰" 키워드가 명제에 들어갔나?
    - [O] "~이다" 형식인가 (동작 묘사 X)?


[4] 3-부분 점검:
    (a) 초기화:
        i = 0 시점에 [3]이 참이려면?
            max_num_list = [arr[0]]
    (b) 유지:
        arr[i+1] < max_num_list[1] 일 때:
            pass
        max_num_list[1] <= arr[i+1] < max_num_list[0] 일 때:
            max_num_list[1] = arr[i+1]
        arr[i+1] >= max_num_list[0] 일 때:
            max_num_list[1] = max_num_list[0]
            max_num_list[0] = arr[i+1]

    (c) 종료:
        arr[i] = len(arr) - 1일 때 max_num_list[1]을 반환


[5] 파이썬 코드:
def solution(arr):
    if len(arr) < 2:
        return None

    # 초기화: 첫 두 원소로 [큰, 작은]
    if arr[0] >= arr[1]:
        big, second = arr[0], arr[1]
    else:
        big, second = arr[1], arr[0]

    for x in arr[2:]:
        if x >= big:
            second = big
            big = x
        elif x > second:
            second = x

    return second if big != second else None
```
