# 알고리즘 사고 훈련

**"수식 사고"에서 "절차 사고"로의 전환** 전용 학습 트랙.

## 배경

본인 진단 (2026-05-27):
- 파이썬 어휘 / 자료구조 기초 충분
- 단일 도구 활용 양호 (Counter, sorted 등)
- **약점**: 변수 간 관계로 풀어왔던 "수식 사고" 패턴이 **알고리즘 사고(절차 시뮬레이션)** 영역에서 안 통함
- 161989 페인트칠 그리디에서 명확히 드러남 (수식 만들기 시도 → 실패)

## 핵심 목표

문제를 받으면 본능적으로 자문하기:

> **"내가 손으로 직접 푼다면 어떤 절차?"**

이게 알고리즘 사고의 진입점.

## 사고 전환 5단계 (모든 드릴 공통)

각 드릴 문제마다 아래 5단계를 채워서 풀이:

```
[1] 문제 읽기
[2] 작은 예시로 사람으로 풀이 (한국말로 3~5줄)
[3] 상태 변수 찾기 (지금까지 본 / 카운트 / 위치 등)
[4] 의사 코드 (3~5줄)
[5] 파이썬 코드
```

**핵심**: [2], [3]에 시간 들이기. 코드는 그 다음 자연 도출.

## 4 Phase 로드맵

### Phase 1: 시뮬레이션 사고 (1주)
"사람으로 푼다면?" 자문이 본능적으로 나오게.
단순한 문제로 5단계 양식 정착.

### Phase 2: 그리디 패턴 (1주)
"최선 선택 반복" 패턴 인식 + 왜 통하는지 직관.

### Phase 3: 상태 변수 추적 (1주)
복잡한 문제에서 여러 상태 변수 동시 관리.

### Phase 4: 엣지 케이스 (1주)
정상 케이스 풀이 후 극단 입력 5개 자동 떠올리기.
