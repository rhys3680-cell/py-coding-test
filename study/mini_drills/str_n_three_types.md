## 핵심 구분 키워드

**문제에 나오는 단어로 즉시 식별**:

- **"합"** → 12931 → `sum`
- **"뒤집어"** → 12932 → `[::-1]` (**순서만** 바꾸기)
- **"내림차순/정렬"** → 12933 → `sorted(reverse=True)` (**크기** 기준)

### 핵심 차이: 뒤집기 vs 정렬

```python
n = 12345

# 뒤집기: 순서만 거꾸로
str(n)[::-1]                    # "54321"
# 입력 순서의 역순. 5→4→3→2→1

# 정렬(내림차순): 크기 기준
sorted(str(n), reverse=True)    # ['5', '4', '3', '2', '1']
# 큰 것부터 작은 것 순. 같은 결과처럼 보일 뿐

# 다른 입력으로 차이 확인
n = 193958
str(n)[::-1]                    # "859391" (순서 역순)
sorted(str(n), reverse=True)    # ['9','9','8','5','3','1'] (크기순)
```

**기억 트릭**:
- **뒤집기 = 거울** (`[::-1]`)
- **정렬 = 줄 세우기** (`sorted`)

## 풀이 한 줄씩

### 12931 자릿수 더하기
```python
def solution(n):
    return sum(int(c) for c in str(n))
```
- 입력: `123` → 출력: `6` (1+2+3)
- 핵심: `sum(int(c) for c in str(n))` — gen-exp + 변환

### 12932 자연수 뒤집어 배열
```python
def solution(n):
    return [int(c) for c in str(n)][::-1]
```
- 입력: `12345` → 출력: `[5, 4, 3, 2, 1]`
- 핵심: 컴프리헨션 후 슬라이싱 `[::-1]`
- **함정**: sorted 떠올리면 안 됨. 입력이 `54321`이라도 뒤집으면 `[1,2,3,4,5]`

### 12933 정수 내림차순 배치
```python
def solution(n):
    return int("".join(sorted(str(n), reverse=True)))
```
- 입력: `118372` → 출력: `873211`
- 핵심: 문자열 정렬 → join → int 변환
- **함정**: 결과가 **정수**여야 함 (12932는 리스트)
