# 미니 드릴 (Mini Drills)

파이썬 도구/패턴을 **반복 노출 + 인출 연습**으로 자동화시키는 짧은 훈련.

## 왜

본인 exp_001 관찰: **"검색하면 쓸 수 있는데 바로 안 나옴"** 상태.
- 이건 재인(recognition) → 회상(recall) 전환 중 단계
- 본격 문제(프로그래머스) 하나당 10~50분 → 노출 빈도 낮음
- **짧은 문제 10개 = 20~30분**으로 같은 시간에 **10배 노출**

## 원칙

1. **한 문제당 1~3분** — 길어지면 본격 문제 성격. 드릴은 빠르게.
2. **도구 1개에 집중** — D1은 Counter만, D2는 sorted key만
3. **같은 도구 10문제 연속** — 반복 노출로 자동화
4. **기록은 간단히** — [log.jsonl](log.jsonl)에 drill_id / 소요초 / 정답 여부만

## 사용 방법

### 매일 루틴 (10~20분)
1. 오늘 드릴 선택 (약점 도구부터)
2. 한 문제씩 풀기 (1~3분)
3. 다 푼 뒤 `solutions/` 와 비교
4. 헷갈린 건 별표 → 3일 뒤 재풀이

### 기록 (간단)
```json
{"date":"2026-04-25","drill_id":"D1-3","duration_sec":45,"correct":true}
```

### 성공 기준
- 10문제 평균 **90초 이내**에 풀면 해당 도구 자동화 도달
- 그 드릴은 **2주 뒤** 랜덤 복습 대상으로 이동

## 주의

- 드릴은 **보조 훈련**. 본격 문제(프로그래머스) 대체 X
- 막히면 **바로 솔루션 보기** (5분 이상 쏟지 말기 — 본격 문제와 다름)
- 풀이가 여러 가지면 **파이써닉한 버전 하나만** 체화 목표
